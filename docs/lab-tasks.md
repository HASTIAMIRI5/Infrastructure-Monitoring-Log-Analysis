# Lab Tasks and Objectives

## Learning Objectives

- Understand how to monitor key infrastructure components
- Learn how to interpret system and application logs
- Practice identifying patterns associated with service degradation and outages
- Build confidence in root-cause analysis and investigation workflows
- Develop professional incident documentation and reporting skills

## Exercise Tasks

### Exercise 1: Resource Review
Review CPU, memory, disk, and network utilization. Record any abnormalities and identify the likely impact on application performance.

### Exercise 2: Service Health Check
Verify whether critical services are running, whether ports are open, and whether dependencies are healthy. Capture evidence of service uptime or failures.

### Exercise 3: Log Review
Review system and application logs for warnings, errors, or critical events. Identify any repeated patterns and note suspected causes.

### Exercise 4: Correlation Analysis
Combine monitoring metrics with log timestamps to establish the sequence of events. Determine which issue appears to be the root cause versus a symptom.

### Exercise 5: Remediation and Validation
Outline corrective actions, validate improvements, and document whether the environment has returned to a healthy state.

## Expected Outcomes

By the end of the lab, participants should be able to:
- monitor core system resources confidently
- analyze logs for meaningful patterns
- identify likely causes of incidents
- produce concise and technical incident summaries
- recommend practical corrective actions
